# infographic-cards

把一份 md 文档做成一套**风格统一、可单张交付的信息图卡片**（每节一张 PNG），再生成一页浏览的配图汇总 HTML。

日常工作中总结沉淀的通用出图流程，解决三个反复出现的痛点：

- **内容和图脱节** —— 强制 md 为唯一内容源，图永远跟着 md 走。
- **风格花哨/不统一** —— 一套"素净版"CSS 视觉系统（中性墨色 + 单一红强调，无 emoji、无多色块、正文居中）。
- **手工截图费事又裁不准** —— 一个 PowerShell 脚本用 Chrome headless 批量渲染、自动裁高、透明背景。
- **内容被版面压缩过度** —— 先核查源文档，再按一个主要结论一张卡拆页；高密度表格和流程可配置更宽画布。
- **内部编号对观众不友好** —— 标题和导航使用自解释的概念名称，编号只作括注或元数据。

## 三段式流水线

```
NN-名.md → 中间产物/NN-*.html → 图片/NN-*.png → 图片/_配图汇总.html
```

## 安装

放到 `~/.claude/skills/infographic-cards/`（本文件所在目录即是）。Claude Code 会自动发现。说"出信息图 / 做配图 / 把文档做成图 / 渲染成 png"等即触发。

## 文件

- `SKILL.md` —— 主说明：铁律 + 四步操作（建目录 → 写 HTML → 渲染 → 汇总页）。
- `assets/_信息图样式.css` —— 共享视觉系统 v3，复制进每套图的 `中间产物/`。
- `assets/渲染图片.ps1` —— html→png 渲染脚本，放目录上一级、多套图共用。
- `assets/term-cards.js` —— HTML 汇报页的术语解释卡片交互；PNG/打印自动隐藏。
- `assets/示例-基础卡.html` —— 基础卡示例（卡头 + 导语 + 多栏 + 标注）。
- `assets/示例-流程图.html` —— 复杂流程图示例（主线 + 分支，分支用淡背景色区分）。
- `assets/示例-宽表格.html` —— 1224px 高密度画布和可横向滚动比较矩阵示例。
- `assets/_配图汇总示例.html` —— 汇总页模板。

> 示例文件均为占位内容，仅演示布局与组件用法。

## 最容易踩的两个坑

1. **视口宽必须等于卡片宽**。默认 900px；高密度内容可设为 1120–1280px，并同步 CSS `--sheet-width` 与渲染脚本 `-Width`，否则会裁切或产生多余留白。
2. **汇总页图片用 `calc(100% - 48px)` + margin**，直接 `100%` 会挤到边缘无留白。
3. **展示稿不能创造源文档没有的事实**。标题直接陈述，避免连续反问；内容过多时优先拆页，不以删减关键证据换取整洁。
